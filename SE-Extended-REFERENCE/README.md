# SE-Extended UI Reference

This folder contains the source code of SE-Extended (from https://github.com/PHATWalrus/SE-Extended) for use as a reference when porting the clean UI into Purrfect.

**Note:** The large `ffmpeg-kit` AAR was excluded to keep the repository size manageable. You can download it separately if needed for building SE-Extended itself.

Key UI-related paths:
- `app/src/main/kotlin/me/rhunk/snapenhance/ui/`
- `common/` (shared UI components)
- Material 3 Expressive redesign, bottom sheets, liquid glass nav, etc.
